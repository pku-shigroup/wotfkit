# WOTF 理论与参考实现核查

本文对应 `refs/pgt_theory.tex`、`refs/analytical.tex`、
`refs/phase_gradient_tomography_solver_gpu.py` 和 `refs/build_wotf_ewald.py`。
这些参考资料保存在作者本地的 `docs/refs/`，不随本包分发，也不是运行依赖。
下文记录核查时的公式与源码行为；两个算法接近本身不是物理正确性的证明。

当前库的网格、传播核和中间变量统一使用角空间频率 k，公开接口为
`k_axes`，返回 `(kz,ky,kx)=2π*fftfreq`，单位 rad/长度。
下面保留原脚本的普通频率 f 和 w 以便追溯转换；它们不再是库的输入约定。
当前实现直接使用 `k_m=2πn_m/λ₀`、`k_{v,z}=sqrt(k_m²−|k_{v,⊥}|²)`、
传播因子 `exp(ik_{v,z}z)` 和散射因子 `1/(2ik_{v,z})`。

角频率下，单边项可直接写为

$$
C(k_\perp,k_z)=\frac1{I_0}\sum_j
\frac{S_jP^*(s_j)P(s_j+k_\perp)}{2k_{v,z}}
\,2\pi\delta(k_z-k_{v,z}+k_{s_j,z}).
$$

有限 lag 核为 `D_N(Δkz,kz)=dz Σ_l exp[i(Δkz−kz)z_l]`；
归一化 sinc 的自变量为 `u=(Δkz−kz)dz/(2π)`。
线性落格位置为 `Δkz/dkz`，总核权重为 `2π/dkz=nz*dz`，
而非 `1/dkz`。傅里叶逆变换的 `1/(2π)³` 已包含于离散 FFT 对的测度换算，
最终预测依然不额外乘体素体积。通道组装使用 `conj(C(−k))`，物理符号与单位不变。

精度统一由 `with precision("float32"):` 或 `with precision("float64"):` 选择；函数的 `dtype=None`
沿用当前上下文，无上下文时默认双精度。显式 `dtype=` 覆盖上下文，退出恢复之前的设置。

## 1. 固定符号、傅里叶与单位

采用时间依赖 `exp(-iωt)`，向前入射平面波为
`u_inc(r)=exp(+2πi s·r)`，真空波长为 λ₀，`f_m=n_m/λ₀`，
`k₀=2π/λ₀`、`k_m=2πf_m`。散射势定义为

$$
F=k_0^2(n_m^2-n^2)=F_R+iF_I,\qquad
(\nabla^2+k_m^2)u=Fu.
$$

`G⁺(r)=exp(ik_m r)/(4πr)` 满足 `(∇²+k_m²)G⁺=-δ`，因此

$$
u_s=-G^+*(Fu_{inc}),\qquad
\widehat u_s(v,z)=\frac{P(v)e^{2\pi i w_vz}}{4\pi i w_v}
\widehat F(v-s,w_v-w_s),\quad w_v=\sqrt{f_m^2-|v|^2}.
$$

这里场仅指检测到的向前传播透射场。焦平面可以通过对出射场重聚焦获得；
不能把该延拓误认为样品内部含前后向波的完整场。

普通频率傅里叶变换为
`F_hat(f)=∫F(r)exp(-2πif·r)dr`，逆变换无前因子。
角频率版本使用 `exp(-ik·r)`，逆变换有 `1/(2π)³`。
其转换必须同时作用于坐标、积分测度和 δ 函数：

$$
\frac{\pi}{k_{v,z}}\delta(k_z-k_{v,z}+k_{s,z})
=\frac{1}{4\pi w_v}\delta(f_z-w_v+w_s).
$$

若 `n=n_R+iκ`、`κ>0`，则 `F_I=-2k₀²n_Rκ<0`。均匀薄层的归一化强度变化为
`c=dz Σ_z F_I/(2πw_s)`，吸收使强度下降，纯实均匀层在线性阶不改变强度。
该解析结果曾用于独立的符号、比例和积分间隔核查；当前精简测试使用独立 Born 场传播检验这些因素。

## 2. 理论文档中需要修正或补足的地方

| 位置 | 核查结论 |
| --- | --- |
| `pgt_theory.tex` 开头 `u_s=+∫GFu_inc` | 与本文所保留的 F 定义和正号 outgoing Green 函数不一致；积分前应为负号。 |
| 同文三维场谱 `F_hat/(k²-k_m²-i0)` | 同样对应上面的正积分；保留 F 定义时，分子需要负号。 |
| FDT 中 `1/(2ik_z)` | 与负积分、向前透射波一致；这是库采用的约定，不对两个实现分别选择符号。 |
| pupil 写成 `|k_perp|<NA/λ` | 文中此处混用了 k 和 f；k 截止应为 `2πNA/λ₀`，f 截止为 `NA/λ₀`。 |
| 强度谱卷积 `eq:ispec` | 在其角频率约定下缺少 `1/(2π)³`；下一步 `eq:cross` 已恢复该常数。 |
| `eq:cross` 第一个展开式的第二散射项 | 出现 `πδ/(2ik_z)` 的额外 1/2，后续等式未保留；不能把该中间行直接当作实现公式。 |
| 最终实部/虚部通道 | 换成普通频率并采用正确 Born 符号后，与本文通道公式一致。 |
| `analytical.tex` 相关定义 | `corr(a,b)(q)=∫conj(a(s))b(s+q)ds` 的方向及其 `ifft(conj(fft(a))*fft(b))` 正确；需补全轴向离散和通道系数。 |

文档声明曾与 Ling 等人核对，但不同文章的散射势符号和 4π 系数不能直接照搬。
[Ling et al. (2018)](https://arxiv.org/html/1801.09773) 定义
`V=k₀²(ε−ε_m)/(4π)`，故在相同介质下 `F=-4πV`；还需要转换其入射波方向约定。
Green 函数的 outgoing 条件与半空间表示可参照
[Sheppard et al. (2014)](https://www.frontiersin.org/journals/physics/articles/10.3389/fphy.2014.00067/full)。

## 3. 统一的两通道公式

`source[j]=S_j` 是网格模式的非相干强度权重，不是场振幅。
若提供连续密度的采样值，应先乘 `dfy·dfx`；归一化模型中共同的积分因子会约去。
允许任意复 pupil。背景必须为

$$
I_0=\sum_j S_j|P(s_j)|^2>0.
$$

`source` 与检测 `pupil` 的支撑独立，照明 NA 不必等于检测 NA。
这里的 `P(s_j)` 是未散射参考光经过检测系统的复振幅透过率，不是额外的照明 pupil。
当 `P(s_j)=0` 时，该光源的背景和线性干涉项都为零；库显式丢弃这些光源并发出一次 warning，
再计算背景、传播条件和采样范围。孔径内非零的振幅透过率与像差完整保留，不设置数值阈值。
若所有光源都被丢弃，则 `I0=0`，不支持用该归一化明场 WOTF 表示纯暗场成像。
被丢弃照明仍可能产生 `|u_s|²`，但它不在线性 WOTF 的适用范围内。

定义不含 `-i` 的单边 cap 项

$$
C(q,f_z)=\frac1{I_0}\sum_j
\frac{S_jP^*(s_j)P(s_j+q)}{4\pi w_{s_j+q}}
\delta(f_z-w_{s_j+q}+w_{s_j}).
$$

实部和虚部空间数组的傅里叶谱分别是 `F_R_hat`、`F_I_hat`。
利用实数组的 `F_hat*(-f)=F_hat(f)`，有

$$
H_R=-i[C-C^*(-f)],\quad H_I=C+C^*(-f),\qquad
\widehat c=H_R\widehat F_R+H_I\widehat F_I.
$$

`H_R` 不是 `real(C)`，`H_I` 也不是 `imag(C)`。普遍成立的约束是两个通道各自
Hermitian，因而实样品得到实强度。仅在实 pupil 和适当的轴向对称性等额外条件下，
才能要求 `H_R` 纯虚、`H_I` 纯实。复 pupil 或偶数轴向有限窗口一般不满足该简化。

## 4. PGT solver 的逐项核查

令 `a(s,z)=S(s)P(s)exp(2πiw_s z)`，
`b(v,z)=P(v)exp(2πiw_v z)/(4πw_v)`，并记
`Q=conj(fft2(a))*fft2(b)`。正确单边项的混合表示为 `ifft2(Q)`。
PGT 使用 `fft2(a)*conj(fft2(b))=conj(Q)`，所以其

```
(2j * ifft2(imag(conj(Q)))) * 1j
```

等于 `-i[corr(a,b)−conj(corr(a,b)(−q,z))]`；
`2*ifft2(real(conj(Q)))` 对应虚部通道。
因此不能孤立删除末尾的 `1j`。此前核查已将原组合与显式直接求和、库实现比较。
这里核查的是通道符号组合。原 solver 的二值检测 pupil 满足 `P²=P`；
其 `prop_kernel` 与 `oblique_factor` 都包含 pupil，若直接替换成复 pupil，会在散射臂多乘一次 P。
库只在每个场臂各放置一次 pupil，不能把复 pupil 支持视为原代码无条件具备的能力。

| 源码行为 | 处理与原因 |
| --- | --- |
| `fftfreq`、`exp(+2πiFz*z)`、`ifftshift` 的 lag 网格 | 约定一致。新接口统一为 `(z,y,x)`，允许非方形与各向异性采样。 |
| 上述反向频域乘积与通道系数 | 组合符号正确；FFT 实现采用 analytical 文档的 A/B 两个相关项，Ewald 实现采用单边项与共轭反射。 |
| 两个预计算因子都含检测 pupil | 对原来的二值 pupil 正确；复 pupil 需要避免重复乘 pupil，库已显式处理。 |
| 相关乘 `dfx*dfy`，背景也乘 `dfx*dfy` | 在强度归一化后约去；新接口直接使用模式权重。 |
| 轴向 FFT 乘 `dz` | 是必需的积分测度，库保留。 |
| 总是乘 Hamming 窗 | 改变了轴向 lag 响应和频谱，不能与无窗 cap 直接比较；库默认不加窗。 |
| `oblique_mode='reference'` | 当 `w²<=f_m²/2` 时用 `f_m` 替代 w，高角度并非准确 `1/w`。 |
| `constant` / `truncated` | 分别是常数近似和截幅近似；库统一使用准确 `1/w`，不支持 grazing/evanescent 活跃模式。 |
| 背景 `sum(src*abs(pupil_ill)**2)` | 仅在所有照明都被单位幅度检测 pupil 接收时等于真正背景；新接口使用检测 pupil 的 `abs(P)**2`。 |
| `imgs/mean(imgs)-1` | 含样品均值不等于空白背景，会抹去平均吸收；库使用显式 I₀。 |

库在相关的两臂都去除公共载波 `exp(2πif_m z)`。它在乘积中严格抵消，是单精度的数值稳定处理，不是近轴近似。

## 5. Ewald 源码与轴向离散

原脚本只支持实二值 pupil；库补全 `conj(P(s))*P(v)`，并以检测到的参考场定义背景。
源码的 `forward` 权重为 `S*nz/(2πw)`，最终乘 `-0.5j` 或 `0.5`。
在本库明示的 F 与体积分约定下，最终单边权重应为 `S*nz*dz/(4πw)`，
原片段缺少 dz。由于仓库没有 `WOTFconfig` 和原脚本的下游预测代码，无法排除原环境曾在外部吸收该系数；
这里不声称完整复现了那个未提供的环境。

**精确有限采样（默认）**：轴向 lag 为
`z_l=ifftshift((arange(nz)−nz//2)*dz)`，把 cap 的 δ 替换为该 lag 序列的准确 DFT：

$$
D_N(\eta,f_z)=dz\sum_l e^{2\pi i(\eta-f_z)z_l}.
$$

令 `u=(η−fz)dz`，按周期一归约到 `[-1/2,1/2)`，则

$$
D_N=Ndz\frac{\operatorname{sinc}(Nu)}{\operatorname{sinc}(u)}
\exp[-i\pi u(1-N\bmod2)].
$$

偶数网格的额外相位来自 lag 范围含 `−N/2`、不含 `+N/2`，不能删除。
本方法按 cap 直接评价该核，不复用 FFT 相关或轴向 FFT。因此两种算法计算同一个有限 lag 算子；
其一致性是代数/数值检验，仍须使用独立 Born 场模型检验物理符号和比例。
交换有限的光源求和与轴向 DFT 就得到两种实现的对应关系；相同输入和采样下数学结果一致，
浮点运算顺序不同则不保证数组逐位相等。实测完整频谱差异见验证报告。

**线性落格**：设 `t=η/dfz`，向 `floor(t)` 和 `floor(t)+1` 分别放入
`(1−frac)/dfz` 和 `frac/dfz`。这保留了原方法的数值思想，但不是上面有限采样核。
误差取决于轴向频率间隔、物体谱和观察范围；同样本数下不应期待与 FFT 相等。
示例在固定物体和固定九个焦平面下扩大轴向计算范围，检验收敛。

**Nyquist 与边界**：

- 原脚本正反 cap 分别裁剪，偶数轴向网格可能只保留一侧 Nyquist 权重，破坏 Hermitian 关系。
  库先累加 C，再统一生成 `conj(C(-f))`；合法落格邻点通过模索引进入唯一的 Nyquist bin。
- 横向物理 `v−s` 及其负频率都必须可表示；活跃 cap 的 `|w_v−w_s|` 必须小于轴向 Nyquist。
  超出时直接报错，而不是靠取模掩盖欠采样。偶数网格排除恰在物理 Nyquist 的横向模式差。
- 3D FFT 乘法实现循环卷积。横向参考物体为周期物体；轴向参考积分是有限切片和。
  验证先补零，使所需 `z_focus−z_sample` 全部位于有限 lag 支撑中，再取中央 ROI。
  若物体占满数组且比较整个输出，边界误差不能算作公式错误。

## 6. 独立验证、证据范围与未解决问题

`examples/validate_born.py::born_stack` 不调用库的网格、传播核、相关、cap 或通道函数。
它将每层 `F*u_inc` 做二维 Fourier 积分，累加到样品外出射面，然后检测并重聚焦。
每层包含显式 `dz` 和 transverse `dx*dy`；二维逆变换包含相应 `1/(dx*dy)`。
多个平面波的强度分别计算后非相干相加。

分别比较线性参考、保留 `|us|²` 的一阶 Born 强度；误差分母是对比度信号，不是接近一的总强度。
此前的薄层解析、长度单位缩放及光源缩放核查额外约束了绝对符号和尺度；当前 pytest 收拢为四项核心行为和小球前向检查。
完整结果见 [validation_report.md](validation_report.md)。

边界与限制：

1. 本验证证明声明的离散、标量、透射、单次散射模型内的一致性，不是对任意连续样品的精确 Maxwell 验证。
2. 一阶 Born 场本身忽略多次散射；WOTF 还忽略 `|us|²`。保留该项的参考强度仍不是多重散射真值。
3. 精确 Ewald 的“精确”指有限 lag 离散算子；横向周期化、体素积分和角度离散仍有连续模型误差。
4. 轴向线性落格需要收敛检查，不能以两算法差值单独判定物理公式错误。
5. 暂不包含离网格照明、反射、倏逝波、掠入射模式、偏振或折射率突变界面的矢量边界效应。
6. 原文符号及中间推导存在以上明确冲突；缺失配置和原数据使旧脚本全部标度无法完整追溯。参考文件保持原样以便继续核查。
